## 中文

**INNNX. · Flutter 聚会小游戏合集**

一部手机轮流玩，以本地题库、玩家轮盘和倒计时组织聚会互动。本仓库用于作品展示，应用源码保持私有。

## 已实现内容

- 真心话大冒险、数字炸弹、谁最有可能、我从来没有、5 秒挑战、生日派对，以及独立真心话、大冒险和混合模式入口。
- 中文、英语、西班牙语界面与题库。
- 玩家名单、随机轮盘、本地设置、背景音乐与音效。
- 广告同意流程和移除广告入口；这些入口不代表已正式上线或完成商店配置。

## 技术栈

Flutter、Dart、SharedPreferences、audioplayers、Flutter 本地化；项目包含 Google Mobile Ads 和 in_app_purchase 集成。

## 当前进度

本地已有 Android 调试 APK 和测试文件。游戏内容可离线使用，广告相关功能需要网络。iOS 工程存在，但本次未验证 iOS 构建。这里不发布安装包，也不宣称已在应用商店上线。

## English

**INNNX. · A Flutter collection of party mini-games**

Pass one phone around and play together using local prompts, a player wheel and countdowns. This repository is a public showcase; the application source code remains private.

### Implemented features
- Truth or Dare, Number Bomb, Most Likely To, Never Have I Ever, 5-Second Challenge and Birthday Party, with separate Truth, Dare and mixed-mode entry points.
- Chinese, English and Spanish interfaces and prompt libraries.
- Player lists, random wheel, local settings, background music and sound effects.
- Ad consent and remove-ads entry points. Their presence does not mean a store launch or completed store configuration.

### Technology and status
Flutter, Dart, SharedPreferences, audioplayers and Flutter localization, with Google Mobile Ads and in_app_purchase integrations.

The existing Chinese README records a local Android debug APK and test files. Gameplay content works offline; ad-related features need a network connection. An iOS project exists, but its build has not been verified. No playable build is currently published in this repository, and no app-store release is claimed.

### Preview
The screenshot above is the existing Chinese home screen. English and Spanish screenshots and a gameplay recording have not yet been added. README translations do not establish that every localized screen has been tested.

### Public scope
Documentation and screenshots only. Application source, signing files, development logs, prompt libraries and local configuration are excluded.

## Español

**INNNX. · Colección de minijuegos de fiesta creada con Flutter**

Una sola persona pasa el teléfono a la siguiente para jugar en grupo, con preguntas locales, una ruleta de jugadores y temporizadores. Este repositorio presenta el proyecto; el código fuente de la aplicación permanece privado.

### Funciones implementadas
- Verdad o Reto, Bomba Numérica, ¿Quién es más probable que…?, Yo Nunca, Reto de 5 Segundos y Fiesta de Cumpleaños, con accesos independientes a Verdad, Reto y modo mixto.
- Interfaz y bancos de preguntas en chino, inglés y español.
- Lista de jugadores, ruleta aleatoria, ajustes locales, música de fondo y efectos de sonido.
- Flujo de consentimiento publicitario y acceso para eliminar anuncios. Su presencia no implica un lanzamiento en tiendas ni una configuración comercial terminada.

### Tecnología y estado
Flutter, Dart, SharedPreferences, audioplayers y localización de Flutter, con integraciones de Google Mobile Ads e in_app_purchase.

El README chino existente indica que hay un APK local de depuración para Android y archivos de pruebas. El contenido del juego funciona sin conexión; las funciones publicitarias necesitan internet. Existe un proyecto para iOS, pero su compilación no se ha verificado. Actualmente este repositorio no publica una versión jugable ni afirma que la aplicación esté disponible en tiendas.

### Vista previa
La captura superior muestra la pantalla de inicio existente en chino. Todavía no se han añadido capturas en inglés y español ni una grabación de una partida. La traducción del README no acredita la validación de todas las pantallas traducidas.

### Alcance público
Solo documentación y capturas. Se excluyen el código fuente, los archivos de firma, los registros de desarrollo, los bancos de preguntas y la configuración local.
